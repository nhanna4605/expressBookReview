# Express Book Review Application

This project is a server-side application for managing book reviews, built using Node.js and Express.

## Features
- Get all books
- Search books by ISBN, Author, or Title
- Register and Login for customers
- Add, Modify, and Delete book reviews
- Uses Promises and Async/Await for asynchronous operations

## Technologies Used
- Node.js
- Express.js
- Axios
- JSON Web Token (JWT)
